# Kimi Code 提示词手册

> 适用范围：这是保留的 Kimi 使用示例，模型名称、上下文容量和个人目录反映当时的运行环境，并非项目要求。新用户从 `README.md` 和 `AGENTS.md` 开始即可；选用下列提示词时，以当前用户的任务和实际目录为准。复制提示词本身不会设置自动唤醒或启动其他 agent。

本手册提供一组可以直接复制使用的提示词，帮助 Kimi Code 与 Kimi K2.7 在约 26 万、且会频繁压缩的上下文窗口中稳定运行 Econ-Variation。提示词统一使用中文，因为面向用户的交流使用中文；除非检索或证据记录需要使用官方中文标题或名称，否则仓库内容、规范记录、任务说明、字段名称和正式文档仍使用英文。

首次维护前先阅读 `guides/mental-model.md`。它是项目思想的唯一解释性入口；本手册只帮助 Agent 进入具体工作模式，不重复定义项目宗旨或质量标准。

每次只使用一条提示词。提示词 1 是无人值守连续工作的默认入口，其余提示词分别对应特定任务。不要把整本手册合并成一条庞大的提示词。持久记忆应由仓库而不是对话承载：每完成一个边界明确的来源或记录任务，Kimi 都应确保任务状态、来源追溯信息、证据和生成文件处于可恢复状态。进入新上下文或上下文压缩后，应依靠 `AGENTS.md` 和 `python scripts/doctor.py` 恢复工作，而不是依赖冗长的文字回顾。

这些提示词重在引导方向和专业判断，而不是罗列密集的禁令。它们不能替代 `AGENTS.md`、`guides/operations.md`、数据结构规范或任务生命周期，而是帮助 Kimi 以正确意图进入并遵循这些既有机制。

## 1. 继续价值最高的工作

当需要 Kimi 在用户不提供新主题的情况下继续推进项目时，使用这条提示词。

```text
请把 Econ-Variation 仓库本身视为本次工作的长期记忆，而不要依赖当前对话中可能很快被压缩的上下文。先阅读 `AGENTS.md` 并运行 `python scripts/doctor.py`，根据仓库当前状态选择一个最有研究价值、同时能够在本轮可靠闭合的下一任务。只读取该任务所需的操作指南、候选记录和来源，不要重新通读全部外生变化记录或历史任务。完成当前任务的认领、证据核验、内容处理、质量门和状态保存后，如果没有真实阻塞，就继续下一个优先级最高的有界任务；每完成一个任务都要先把判断和进度持久化，再开始下一项，使任何时点发生上下文压缩都不会丢失工作。始终围绕中国实证研究价值决定优先级，正式仓库内容使用英文，向我用中文简洁汇报已完成内容、证据质量、记录状态、剩余风险和下一步。不要为了显得有进展而降低证据标准或提升成熟度，也不要让历史维护无限挤占新的高价值知识收集。
```

## 2. 开展主题导向的持续收集

当需要围绕某一主题持续收集时，使用这条提示词。可以在最后一行填写主题；如果留空，Kimi 应自主选择一个高价值的知识覆盖缺口，而不是停下来要求用户补充说明。

```text
请围绕本消息末尾给出的主题开展一轮持续但可恢复的 Econ-Variation 收集工作。先阅读 `AGENTS.md`、运行 `python scripts/doctor.py`，并用现有搜索和健康信息确认该主题是否已有记录、候选或重复线索，再从高质量经济学及相关领域文献中寻找真正能够还原处理分配机制的中国相关外生变化、直接影响中国的全球变化，或具有明确中国迁移价值的识别方法。不要一开始就批量编写政策卡片；先筛选来源，再逐个完成身份边界确认、制度背景梳理、时间与处理分配还原、论文设计分析、数据要求分析、识别威胁评估和证据定位。每篇来源和每条规范案例都应作为可独立闭合的工作单元，完成并保存后再继续，以抵抗频繁的上下文压缩。优先形成少量足以支持决策的可靠记录，而不是积累大量看似丰富但无法推荐的线索；若主题未填写，则根据当前可推荐内容的覆盖缺口，自主选择一个对中国研究价值高且原始制度证据可获得的主题继续，不要因此停住。正式内容写英文，向我用中文汇报。

主题（可选）：
```

## 3. 批量筛选来源而不污染正式知识目录

当用户已有论文清单，或希望在深入抽取前进行高效筛选时，使用这条提示词。

```text
请对本消息末尾的文献清单进行高效率范围筛选。先按 `AGENTS.md` 和诊断结果恢复仓库状态，并把每篇文献作为独立的 `screen` 类型任务依次处理，不要在筛选阶段直接修改规范记录。对每篇文献先判断它属于中国相关外生变化、面向中国的全球变化、可迁移识别方法，还是不应保留；判断依据是能否还原有识别价值的分配、阈值、时点、边界、随机化、暴露或工具变量构造，而不是期刊声望或关键词相似。通过筛选的来源应留下去重所需的稳定指纹、清楚的保留理由和独立后续任务；未通过的来源应明确标记为 `skip`（跳过），证据暂时无法取得则应如实标记为 `blocked`（阻塞）。每完成一篇就闭合并保存其任务状态后再处理下一篇，这样上下文压缩不会让同一文献被重复筛选。清单为空时，可从当前主题中选择三到五篇高相关来源开始，但仍应逐篇完成任务。最后用中文给出简洁的保留、跳过、阻塞及后续任务概览。

文献或 DOI 清单（可选）：
```

## 4. 确认外生变化的身份边界并处理重复记录

当某个政策家族、分批实施过程、阈值或现有记录的边界不清时，在正式抽取前使用这条提示词。

```text
请处理当前队列中优先级最高的 `resolve`（边界确认）或 `consolidate`（合并整理）问题；如果我在消息末尾指定了候选，则以该候选为目标。先运行诊断命令，搜索 `variations` 目录、候选台账、别名、DOI、法律标识和分配机制指纹，判断它究竟是一条新的外生变化、现有记录所描述的同一案例、应拆分的政策家族，还是不具备可还原识别来源的线索。划分边界时关注“一种制度工具、一个实施制度、一个主要分配机制”，不要因为政策名称相同就合并不同批次、不同地方实施、不同阈值或不同处理边际，也不要因论文不同而重复创建同一外生变化。用原始制度文件和论文设计说明支持最终边界，保留必要的 `related`、`parent`、`superseded` 或 `contested` 关系，并把无法确认的部分列为阻塞项。只在边界真正解决后进入抽取或合并，完成质量门和任务状态更新，再用中文说明为什么合并、拆分、保留或放弃。

候选或记录（可选）：
```

## 5. 对中国相关外生变化进行证据夯实

当需要把一条已保留的中国相关线索转化为可靠且足以支持研究决策的知识时，使用这条提示词。

```text
请对本消息末尾指定的中国相关外生变化开展一次以研究可用性为目标的证据夯实；若未指定，则从诊断工具推荐且最有希望成为 `conditional candidate`（有条件可用候选）的记录中选择一条。不要把“补齐字段”当作目标，而要让未来的 Agent 能够据此判断某个研究想法是否真的适配。先核验政策或制度的原始文件，再核对高质量论文正文、附录或复制材料，连贯解释改革前制度、变化动因、正式规则、实施过程、受影响对象、时间、地方裁量、例外和同期政策。随后还原处理组、对照组、暴露强度、连接键、论文如何编码处理、实际使用数据、识别假设、诊断和威胁。明确区分已验证事实、论文报告和分析推断；每项证据都要写明实际访问层级和可复查的 `locator`（定位信息）。找不到的核心信息应列为阻塞项，而不是用看似合理的猜测填满。完成后根据证据的真实程度决定状态，不追求升级本身，并闭合任务、通过质量门。正式记录使用英文，向我用中文汇报其研究价值、尚存条件和是否值得推荐。

目标外生变化（可选）：
```

## 6. 收集直接影响中国的全球变化

当贸易规则、国际冲击、全球事件或源自境外的变化会给中国带来可测量的暴露时，使用这条提示词。

```text
请围绕一个直接改变中国研究单位所受暴露的全球或境外变化开展收集。先从 `AGENTS.md` 和诊断结果中恢复状态，并确认它对中国的作用不是泛泛的宏观相关性，而是存在可观察的中国处理对象、暴露强度、时间或比较结构。记录应以中国面对的处理边际为中心：哪些中国地区、行业、企业或群体受到什么变化，如何构造处理组和对照组，怎样连接中国数据，以及全球同期冲击和一般均衡效应会如何破坏因果解释。境外制度历史只保留理解中国处理分配所必需的部分；如果该事件没有直接作用于中国，但方法可以迁移，则转入 `transferable-method`（可迁移方法）类别，而不是勉强建立面向中国的全球变化记录。逐项核验国际规则或官方来源与论文应用，完成任务并通过质量门后，用中文说明它为何真正属于 `global-china-variation`（面向中国的全球变化），或为何应改道、跳过或阻塞。

主题或来源（可选）：
```

## 7. 提取可迁移的海外识别方法

当海外研究中的工具变量、模拟资格指标、移位—份额构造、边界、阈值或随机化设计可能启发中国研究时，使用这条提示词。

```text
请从指定的非中国高质量研究中提取真正可迁移的识别构造，而不是完整收集当地政策本身。先阅读 `AGENTS.md`、运行 `python scripts/doctor.py`，并确认该论文的方法价值能够超越原国家背景。重点还原内生变量、工具变量或比较构造的精确定义、第一阶段来源、排除限制或核心识别假设、所需数据、关键诊断、安慰剂检验和失败方式；随后寻找是否已有中国应用，或中国是否具备相近的制度与数据条件，说明哪些部分可以迁移、哪些只属于原研究环境，以及在中国使用前必须重新验证什么。若缺乏可执行的中国对应方案，应保留为 `method lead`（方法线索）或直接标记为 `skip`（跳过），不能仅因设计著名就将其包装成方法启发；若已有足够的论文、复制材料和中国证据，仍应如实保留迁移限制。任务处理要在一个边界明确的方法案例内完成并保存，正式内容写英文，向我用中文汇报构造步骤、中国可行性和最关键的阻塞条件。

论文、DOI 或方法（可选）：
```

## 8. 高效升级一条历史线索

当历史维护确有价值、但需要避免再次陷入无休止的积压修补时，使用这条提示词。

```text
请从历史积压中选择一条最值得升级的记录，但先证明这次维护能够明显增加用户价值。优先考虑研究需求常见、处理分配清楚、原始制度证据可获得、论文数据路径可还原，并且升级后有希望成为 `conditional candidate`（有条件可用候选）或可靠方法启发的记录；不要按文件顺序机械修补，也不要一次认领多条历史记录。运行 `python scripts/doctor.py`、创建并认领真实任务后，重新核验身份边界、原始政策文件、论文设计、数据和威胁，使被触碰的记录达到当前标准。如果发现它不是外生变化、混合了多个机制、与现有记录重复或无法可靠验证，应选择拆分，将其标记为 `contested`（存在争议）或 `deprecated`（已弃用），或保持线索状态，而不是为了回报既有投入而强行升级。完成一条后运行质量门，并根据健康状态判断下一步应继续升级还是回到新知识收集。用中文说明这条记录为什么值得维护、实际改善了什么，以及下一项工作是否仍有更高的边际价值。
```

## 9. 为研究想法匹配外生变化与数据要求

当用户提出研究问题、初步想法或已有数据集时，使用这条提示词。

```text
请把我在本消息末尾描述的研究想法转换为结果变量、研究对象、地区、时期、观察单位、频率、机制、已有字段、连接标识和现实约束，然后按照 `AGENTS.md` 中的研究想法匹配路径工作。先用紧凑搜索分别召回中国相关外生变化、面向中国的全球变化和可迁移方法，再用结构化匹配检查知识成熟度与数据兼容性，只打开少量最相关的规范记录。不要把关键词相似当成真正适配，也不要把海外方法当成发生在中国的冲击；如果成熟记录不足，应明确报告知识缺口，并可将最接近的线索作为“需要先审计的线索”单独说明。最终用中文比较少量候选，解释制度匹配、处理与对照、可利用差异、所需数据和连接键、可能采用的研究设计、关键假设、识别威胁，以及下一步最值得验证的问题。结论可以是 `conditional`（有条件适配）、`incompatible`（不兼容）、`method-only`（仅可借鉴方法）或 `gap`（存在缺口），不必为了给出答案而强行推荐。
```

## 10. 联合 Econ-Variation 与经济数据知识库进行匹配

当同一个 AI Agent 可以同时读取 Econ-Variation 和另一个数据知识库时，使用这条提示词；先将 `<数据知识库目录>` 替换为实际位置。

```text
请围绕我在本消息末尾提供的研究想法，联合读取 Econ-Variation 与 `<数据知识库目录>`，但保持两个项目的职责和状态彼此独立。分别遵循两个仓库各自的 Agent 说明，先在外生变化一侧寻找有识别价值的变化及其实证数据要求，再在数据一侧寻找真实可获得或可以构建的数据能力；不要因为主题相似就宣称二者能够连接。逐项比较研究对象、观察单位、地域层级、时间覆盖、频率、结果变量、处理构造、字段、访问条件和连接标识，说明哪些组合兼容、哪些有条件兼容、哪些不兼容。允许研究问题、数据和外生变化之间迭代收敛：如果现有问题无法成立，可以提出最小幅度的研究对象、时期或数据调整，但不要暗中改变核心研究问题。最终用中文给出少量“外生变化 × 数据 × 研究设计”组合、成立所需条件、最大风险和仍然缺失的证据；不要向任一仓库写入对方的内部标识，也不要制造紧耦合。

研究想法：
```

## 11. 在上下文压缩或任务中断后安全恢复

当 Kimi 刚刚压缩上下文、丢失对话细节或恢复一项中断任务时，立即使用这条提示词。

```text
当前上下文可能已经压缩或丢失，请不要依据残余对话猜测之前做到哪里，也不要重新从头扫描整个仓库。把持久化仓库视为唯一可信交接：先阅读 `AGENTS.md`，运行 `python scripts/doctor.py`，检查是否存在活动任务、租约、候选、失败状态或过期的生成文件，再只打开该任务对应的记录、来源和操作指南相关章节。若已有有效认领，就从已保存的证据和任务状态继续；若租约过期、令牌不匹配或上次执行失败，则使用项目已有的 `renew`（续租）、`retry`（重试）、`release`（释放）或 `reclaim`（重新认领）流程恢复，而不是重复创建任务或绕过状态管理。若没有活动任务，再选择诊断工具给出的安全下一步。恢复后先完成一个最小可闭合单元并通过质量门，再继续长期工作；所有正式内容使用英文，向我用中文给出很短的恢复说明、当前真实状态和接下来正在执行的动作。
```

## 12. 复盘知识组合价值并防止维护偏航

当若干任务已经完成、准备开始新一轮长期运行，或收集工作似乎逐渐被修补任务主导时，使用这条提示词。

```text
请进行一次只读的阶段性产品复盘，用来决定接下来一段时间应收集新知识、夯实高价值候选，还是处理少量真正阻碍使用的历史债务。先运行 `python scripts/doctor.py`，并结合健康状态、候选队列、最近完成的任务和默认检索结果判断：哪些研究主题缺少可推荐的外生变化，哪些线索最接近产生真实用户价值，哪些维护只是让文件看起来更整齐却不会改善匹配。不要用记录数量、测试全部通过或字段完整代替研究可用性，也不要因为存在大量历史债务就默认逐条修复。给出一个很短的下一阶段优先顺序，并立即认领其中第一个可执行任务继续工作；每完成若干有界任务再复盘一次，避免目标漂移和标准退化。只有当来源不可访问、外部资源不足、仓库状态异常，或确实需要用户作出会改变结果的选择时才停下，并用中文留下足以支持下一次上下文压缩后继续工作的简洁交接。
```

---

这些提示词刻意不要求 Kimi“记住一切”。长期运行的可靠性来自反复从仓库中恢复目标与状态、每次闭合一个边界明确的任务，以及拒绝把缺失的证据包装成确定无疑的文字。

执行时应把研究价值和证据质量放在首位，并在每个有界任务完成后把状态可靠保存到仓库，避免长时间运行中的质量下降与目标偏移。
