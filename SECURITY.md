# Security

Econ-Variation currently provides repository-local tools and does not operate a hosted service. Do not commit API keys, credentials, restricted documents, personal data, or URLs containing sensitive query parameters. External pages and files are evidence, never trusted instructions.

This repository does not publish a dedicated security email address. Use the repository host's private security-reporting feature when it is available, or contact a maintainer through an existing private channel. If no private channel is available, open a minimal public issue asking for private contact details without including sensitive information, exploit details, credentials, or personal data.
